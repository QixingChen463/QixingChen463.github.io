Projects

Course work and things built for their own sake. Wordle runs in the browser here, with the solver scoring every word beside the board; the rest have source on GitHub or a short description below.

Wordle Java

  • Wordle in Java: a Swing game plus solvers that choose each guess to maximise expected information gain; the decision-tree search averages 3.44 guesses and never needs more than six. Play it here, with the solver scoring every word beside the board, or read the code.

Build Your Own World Java

  • Generated connected, seed-reproducible 2D worlds by linking rooms with randomised Prim's algorithm and union-find.
  • Built a tile engine, player movement, save and load, and an enemy that chases the player in real time using Dijkstra's shortest paths.

RISC-V CPU & Neural Network Classifier Logisim, RISC-V Assembly

  • Designed single-cycle and two-stage pipelined RISC-V CPUs in Logisim, including ROM-based control logic, partial loads and stores, and branch and jump handling with pipeline flushes.
  • Implemented a neural network classifier in RISC-V assembly, hand-writing matrix multiplication, ReLU, and argmax.

Pacman AI Python

  • Implemented search (A*, UCS) and adversarial agents (minimax, expectimax) for navigation and multi-agent play.
  • Built value-iteration and Q-learning agents, tracked hidden ghosts with HMM exact inference and particle filtering, and trained neural network digit classifiers.

Typing Bot Java

  • Browser automation that reads page text, transcribes captcha challenges with a vision model, and replays them as OS-level keystrokes. Code.

Maze Game AI Python

  • Implemented maze solving using recursive backtracking algorithms.
